# Site audit report contract

Use this structure for both the concise response and any saved report.

## 1. Coverage

- target and canonical domain
- audit ID and retrieval date
- requested scope and actual pages crawled
- Lighthouse coverage
- blocked, skipped, or failed pages

## 2. Executive summary

Give an evidence-based status for each dimension:

- Technical SEO: critical / needs work / healthy / not assessed
- On-page and content: critical / needs work / healthy / not assessed
- GEO readiness: critical / needs work / healthy / not assessed
- AEO readiness: critical / needs work / healthy / not assessed
- Performance: critical / needs work / healthy / not assessed

Do not manufacture a numeric score unless a referenced tool returns one or the report defines and shows a reproducible rubric.

## 3. Top actions

List exactly three actions when three supported actions exist. Prioritize blockers, then high-impact low-effort fixes, then structural improvements.

## 4. Findings

| Severity | Finding | Evidence and URLs | Why it matters | Recommended action | Impact | Effort | Source |
| --- | --- | --- | --- | --- | --- | --- | --- |

Separate sitewide findings from single-page findings. Consolidate repeated template problems rather than listing the same fix hundreds of times.

## 5. What works

Include genuine strengths with specific evidence. Do not add generic praise.

## 6. Limitations

State missing integrations, blocked coverage, sampling, unavailable measurements, and any inference explicitly.

## 7. Next check

Recommend when to re-run the audit and which result should change if the fixes work.
