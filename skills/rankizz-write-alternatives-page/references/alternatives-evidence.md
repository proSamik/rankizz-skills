# Alternatives-page evidence standards

Use current primary sources for product capabilities, prices, limits, policies, and migration behavior. Use independent sources only for claims they can directly support. Recheck these standards before publication because search features and commercial-disclosure rules change.

- [Google: create helpful, reliable, people-first content](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)
- [Google: write high-quality product reviews](https://developers.google.com/search/docs/specialty/ecommerce/write-high-quality-reviews)

## Working rules

- Show expertise through original analysis, first-hand evidence when real, current sources, quantitative measurements where appropriate, and meaningful benefits and drawbacks.
- Do not create scaled, substantially similar competitor pages that add little value.
- Place a clear commercial disclosure with the recommendation it affects. A vague footer is not enough.
- Mark paid links using the publisher's implementation rules and current search guidance.
- Use review or product structured data only for content and entities that meet current eligibility and visible-content requirements.
