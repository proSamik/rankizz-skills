# Keyword clustering rules

## Strong same-page evidence

- the same user task and desired outcome
- substantially overlapping ranking pages in the same market
- the same expected page type
- one term is a modifier, synonym, or narrower subtopic that can be satisfied naturally
- one page can answer all terms without becoming unfocused

## Strong separate-page evidence

- informational versus transactional intent
- category versus individual product/service intent
- comparison versus product landing page
- different local markets requiring distinct information
- SERPs dominated by different page types or entities
- one combined page would make either task difficult to satisfy

## Existing-page decisions

- **Keep:** one page already fits and has supporting evidence.
- **Refresh:** the page fits but coverage or targeting is weak.
- **Consolidate:** several pages compete for the same task without distinct value.
- **Split:** one page mixes materially different intents.
- **Create:** no current page satisfies the cluster.
- **Exclude:** no strategic fit or misleading intent.
